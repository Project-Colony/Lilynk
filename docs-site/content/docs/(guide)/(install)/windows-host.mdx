---
title: "Windows Host"
description: "Run the Lilynk host on a Windows 11 PC: a setup you build, with its own virtual display, gamepad drivers and web console."
---

Stream a Windows 11 PC's desktop or games to any Lilynk client, at the client's exact
resolution and refresh, HDR included, with no second monitor or dummy plug. To stream *to* a
Windows PC, see the [Windows client](/docs/clients#windows-desktop-client).

The host runs as a `LocalSystem` service, so it can capture UAC prompts and the lock screen and
stream with nobody signed in. That makes it a high-privilege component: keep it on a trusted
network and read [Security & Safe Use](/docs/security).

## What you need

- **Windows 11 22H2 (build 22621) or newer, x64.** Setup refuses anything older, Windows 10
  included: the virtual-display driver needs IddCx 1.10, which first shipped in 22H2. An ARM64
  build streams video but no audio, with Media Foundation as its only encoder.
- **A GPU with a hardware encoder:** NVIDIA (NVENC), AMD (AMF) or Intel (QSV), picked
  automatically. Windows has no software encoder.
- **Steam installed and opened once** for game audio and the microphone. After that it never has
  to run. Without it the host streams video only, and picks Steam up within minutes of its first
  start.
- **Windows Server 2025** takes the same setup, for [seats](/docs/windows-seats).
  [Prepare the server](/docs/windows-seats#prepare-windows-server) first.

## Install

<Install platform="windows" />

Build the host and pack its setup as
[Build from source](/docs/developers/build-from-source#windows-host-and-client) describes, then run
the `lilynk-host-setup-<ver>.exe` that `pack-host-installer.ps1` writes.

The wizard's **Configure** step lists what it sets up. The defaults suit most PCs:

| Row | What it is | Default | Task |
| --- | --- | --- | --- |
| **Virtual display driver** | The display the host streams from. Required. | on | `installdriver` |
| **Controller drivers** | Controllers arrive as real gamepads. | on | `installgamepad` |
| **HDR Vulkan layer** | HDR for Vulkan and DXVK games. | on | `installhdrlayer` |
| **Moonlight support** | GameStream for stock [Moonlight](/docs/moonlight). Trusted LAN only. | off | `gamestream` |
| **Public-network firewall rules** | Opens the firewall on networks marked Public too. | off | `allowpublicfw` |
| **Start the service** | Streams as soon as setup finishes. | on | `startservice` |
| **Tray autostart** | The status icon next to the clock. The console can change it later. | on | `trayicon` |
| **Web console reachable from** | Your network, this PC only, or one address. | your network | — |
| **Web console password** | Keep the generated one or type your own. | generated | — |

- **Network set to Public?** The wizard offers to make it Private or to open the firewall there.
  Skip both and clients can't connect ([Windows firewall](/docs/troubleshooting#windows-firewall)).
- **Sunshine, Apollo, Vibeshine, Vibepollo or LuminalShine set to start on its own?** Setup moves
  Lilynk's management API to TCP 47991 and keeps Moonlight support off
  ([Switching from Sunshine](/docs/switching-from-sunshine)).

### Unattended install

```powershell
lilynk-host-setup-<ver>.exe /VERYSILENT /SUPPRESSMSGBOXES
```

Change a default with `/MERGETASKS` and the task names above: a bare name turns a task on, `!name`
turns it off. `/WEBBIND=localhost` keeps the console on this PC (`lan` or an address also work).

An upgrade always updates both drivers and keeps your earlier Moonlight, firewall, console,
HDR-layer and tray choices. A silent install shows no console password: print it from an elevated
PowerShell with `lilynk-host web password` before your first sign-in.

### About the signatures

`pack-host-installer.ps1` signs setup and the Lilynk programs with a throwaway self-signed
certificate (`CN=Lilynk`), or not at all with `-NoSign`, so Windows names no known publisher. If
SmartScreen shows *"Windows protected your PC"*, choose **More info** → **Run anyway**. The drivers
carry a separate self-signed certificate (`CN=lilynk-driver`). Setup adds it to the machine's
**Trusted Root** and **Trusted Publishers** stores, and uninstalling removes it.

## Good to know

- **Status icon.** It shows whether the host is running. Its menu opens the console and the logs
  folder, approves pairing, and starts, stops or restarts the host, each behind a UAC prompt.
  While **Tray autostart** is on, the service restarts the icon if it closes;
  [`lilynk-host tray`](/docs/host-cli#tray-windows) controls it by hand. **Lilynk Host** in
  the Start menu opens it and starts a stopped host.
- **Settings.** Change them in the console under **Host**; **Moonlight support** is
  **GameStream** there. A line in `%ProgramData%\lilynk\host.env` pins a setting. After editing
  it, run `lilynk-host service restart` from an elevated prompt. See
  [Configuration](/docs/configuration).
- **Encoder.** `LILYNK_ENCODER` in `host.env` forces `nvenc`, `amf`, `qsv` or `mf` (Media
  Foundation). A pin that doesn't match the selected GPU's vendor is ignored. When the native
  encoder can't open, an 8-bit SDR session falls back to Media Foundation. NVENC has the most field
  time; AMF and QSV see less.
- **HDR.** For a 10-bit session the host turns HDR on for its virtual display; you never touch
  **Use HDR** in Windows. See [HDR → Windows](/docs/hdr#windows).
- **Logs.** `%ProgramData%\lilynk\logs\` holds `service.log` and `host.log`, each rotated at
  10 MB. Only Administrators can read them, so use an elevated PowerShell or **Diagnostics** →
  **Troubleshooting** in the console. `RUST_LOG=debug` in `host.env` adds detail.
- **Several people, taking turns.** Give each person their own account, Steam and saves with a
  [take-turns profile](/docs/profiles#on-windows) — any edition, no extra licence. Playing at the
  **same time** is the part that needs **Windows Server** and a Remote Desktop Services CAL per
  player ([Seats on Windows](/docs/windows-seats)); [Windows 11](/docs/windows-seats#windows-11)
  runs one desktop at a time.
- **Two processes.** Task Manager shows two `lilynk-host.exe`: the service and the worker it
  starts in your session. Ending the worker only makes the service start another; stop the host
  from the status icon or with `lilynk-host service stop`.

## Updating

Pull the clone, build and pack setup again, and run the new setup over the old one. It keeps your
config, pairings and console password. See [Updating](/docs/updating).

## Uninstalling

Open **Settings** → **Apps** → **Installed apps** → **Lilynk Host** → **Uninstall**. It turns [seats](/docs/windows-seats) off and removes the
service, the status icon and its Start menu entry, the virtual display, gamepad and audio devices
with the driver certificate, the scheduled task, the firewall rules, the HDR layer and the `PATH`
entry. `%ProgramData%\lilynk` stays, so
a reinstall keeps your identity and pairings; [Uninstall → Windows host](/docs/uninstall-windows)
clears it.
