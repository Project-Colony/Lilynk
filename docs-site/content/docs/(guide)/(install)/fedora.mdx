Install the host on **Fedora 43, 44 or 45**, Workstation or KDE. Bazzite and other Fedora Atomic spins
have [their own page](/docs/bazzite).

## 1. GPU driver

- **NVIDIA:** the driver comes from **RPM Fusion**. Enable it, install, reboot:

  ```sh
  sudo dnf install \
    https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
    https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
  sudo dnf install akmod-nvidia xorg-x11-drv-nvidia-cuda
  ```

  With Secure Boot on, the module won't load until you enrol its key:
  [Troubleshooting](/docs/troubleshooting#nvidia-smi-says-it-cant-communicate-with-the-driver).
- **AMD / Intel:** nothing to install; Mesa carries Vulkan Video and VAAPI. For every codec, add RPM
  Fusion's `mesa-va-drivers-freeworld` (AMD) or `intel-media-driver` (Intel).

## 2. Install the host

<Install platform="fedora" />

Build the RPMs in the Fedora builder image from
[Build from source](/docs/developers/build-from-source#fedora), with your release as
`FEDORA_VERSION` (`rpm -E %fedora` prints it). Inside the image, in a clone, build them with the
console and the plugin runner:

```sh
PF_VERSION=0.47.0 PF_RELEASE="$(git rev-list --count HEAD)" PF_WITH_WEB=1 PF_WITH_SCRIPTING=1 \
  bash packaging/rpm/build-rpm.sh
```

Then install what it wrote to `dist/` on the host:

```sh
sudo dnf install ./dist/*.rpm
```

To update, run `git pull && rm -rf dist` in the clone, then both again. The commit count in
`PF_RELEASE` lets dnf replace the installed packages.

## 3. Let it use your controllers

Join the groups, then **restart the computer**:

```sh
sudo usermod -aG input "$USER"       # virtual gamepads
sudo usermod -aG lilynk "$USER"   # virtual Steam Deck controller
```

## 4. Start it

From a terminal inside your desktop session:

```sh
systemctl --user enable --now lilynk-host lilynk-web
```

Fedora runs **firewalld**, and no client reaches the host until you open it. Open the host, and the
console for other devices:

```sh
sudo firewall-cmd --reload   # load the service definitions the package installed
sudo firewall-cmd --permanent --add-service=lilynk-native --add-service=lilynk-web
sudo firewall-cmd --reload
```

For [Moonlight](/docs/moonlight), also add `lilynk-gamestream` ([Ports & firewall](/docs/ports)).
