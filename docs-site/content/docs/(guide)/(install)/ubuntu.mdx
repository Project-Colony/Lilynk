Install the host on **Ubuntu 26.04 or newer**, Desktop or Server. Ubuntu 24.04 installs the
package but can't stream: its desktop is too old
([Requirements](/docs/requirements#the-floor-for-a-working-host)).

## 1. GPU driver

- **NVIDIA:** install the recommended driver and its GL/EGL userspace, which Wayland needs, then
  reboot:

  ```sh
  sudo ubuntu-drivers install
  sudo apt install libnvidia-gl-<version>   # the number ubuntu-drivers picked, e.g. 580
  ```

  If `nvidia-smi` can't reach the driver afterwards, Secure Boot is blocking it:
  [Troubleshooting](/docs/troubleshooting#nvidia-smi-says-it-cant-communicate-with-the-driver).
- **AMD / Intel:** nothing to install. The host package pulls in the VAAPI drivers, and Mesa
  carries Vulkan Video.

## 2. Install the host

<Install platform="debian" />

Install the build tools with the `apt install` line in
[Build from source](/docs/developers/build-from-source#ubuntu--debian), and [bun](https://bun.sh)
for the console and the plugin runner. Then build the host, the console and the plugin runner as
packages, and install them:

```sh
git clone https://github.com/Project-Colony/Lilynk.git lilynk && cd lilynk
cargo build --release --locked -p lilynk-host -p lilynk-encode-worker -p lilynk-seats \
  --features lilynk-host/nvenc,lilynk-host/vulkan-encode
export VERSION="0.47.0+git$(git rev-list --count HEAD)"
for s in deb seats-deb bun-deb web-deb scripting-deb; do bash packaging/debian/build-$s.sh; done
sudo apt install ./dist/*_"$VERSION"_*.deb
```

To update, run `git pull && rm -rf web/.output` in the clone, then every line after `git clone`
again. The commit count in `VERSION` lets apt replace the installed packages.

## 3. Let it use your controllers

Join the groups, then **restart the computer**:

```sh
sudo usermod -aG input "$USER"       # virtual gamepads
sudo usermod -aG lilynk "$USER"   # virtual Steam Deck controller
```

## 4. Start it

From a terminal inside your desktop session:

```sh
systemctl --user enable --now lilynk-host lilynk-web
```

Ubuntu ships `ufw` turned off. If you turned it on, open the host, and the console for other
devices:

```sh
sudo ufw allow lilynk-native && sudo ufw allow lilynk-web
```

**Next:** [Quick Start, step 3](/docs/quickstart#3-open-the-web-console): open the console and pair
a device.
