Install the host on **Arch Linux** and Arch-based distros such as CachyOS and EndeavourOS. Omarchy
and SteamOS have their own pages: [Omarchy](/docs/omarchy), [SteamOS](/docs/steamos-host).

## 1. GPU driver

- **NVIDIA:** `sudo pacman -S --needed nvidia-utils`. NVENC comes from it.
- **AMD / Intel:** the Mesa stack a desktop usually has already: `vulkan-radeon` or `vulkan-intel`
  for Vulkan Video, `libva-mesa-driver` or `intel-media-driver` for VAAPI.

## 2. Install the host

<Install platform="arch" />

Build the packages with the `PKGBUILD` in a clone, with `PF_WITH_WEB=1` and `PF_WITH_SCRIPTING=1`
so the console and the plugin runner are built too, then install the host, the console and the
plugin runner with `sudo pacman -U`
([Build from source → Arch](/docs/developers/build-from-source#arch-pkgbuild)).

To update, `git pull` in the clone and build and install the packages again.

## 3. Let it use your controllers

Join the groups, then **restart the computer**:

```sh
sudo usermod -aG input "$USER"       # virtual gamepads
sudo usermod -aG lilynk "$USER"   # virtual Steam Deck controller
```

## 4. Start it

From a terminal inside your desktop session. The install already enabled the plugin runner for
every user; this starts it with the host and the console:

```sh
systemctl --user enable --now lilynk-host lilynk-web lilynk-scripting
```

Stock Arch has no firewall. **CachyOS** enables `ufw` and **EndeavourOS** enables firewalld; open
the host, and the console for other devices:

```sh
# ufw (CachyOS)
sudo ufw allow lilynk-native && sudo ufw allow lilynk-web
# firewalld (EndeavourOS)
sudo firewall-cmd --reload
sudo firewall-cmd --permanent --add-service=lilynk-native --add-service=lilynk-web
sudo firewall-cmd --reload
```

a device.
