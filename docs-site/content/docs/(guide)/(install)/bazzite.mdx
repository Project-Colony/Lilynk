Install the host on **Bazzite** or another Fedora Atomic spin. Bazzite already ships the GPU driver,
gamescope and KDE Plasma, and one host streams both **Gaming Mode** and the **KDE desktop**,
following the box when you switch.

## 1. Install the host

The host installs as a **systemd system extension**: no `rpm-ostree` layering, no reboot, and it
survives OS updates.

<Install platform="bazzite" />

Build the RPMs as on [Fedora, step 2](/docs/fedora#2-install-the-host), with your Fedora release
(`rpm -E %fedora`). In the same Fedora image, wrap them into an image with
`packaging/bazzite/build-sysext.sh`; its header lists the arguments. Then install the image on
the box:

```sh
sudo bash packaging/bazzite/lilynk-sysext.sh install --from-file lilynk-X-x86-64.raw
```

The image holds the host, the console, the tray and the plugin runner, plus the HDR
`lilynk-gamescope` build when you pass `--gamescope-stage`. To update, build a new image and run
`sudo lilynk-sysext update --from-file lilynk-X-x86-64.raw`. `sudo lilynk-sysext status` shows the
installed build.

## 2. Let it use your controllers

Bazzite manages the `input` group through a recipe, so use it instead of `usermod`. Then **restart
the computer**:

```sh
ujust add-user-to-input-group add    # virtual gamepads
sudo usermod -aG lilynk "$USER"   # virtual Steam Deck controller
```

## 3. Start it

Enable the services and linger from a terminal in the desktop session. Without linger the host
waits for a login that a headless box never gets:

```sh
systemctl --user enable --now lilynk-host lilynk-web
sudo loginctl enable-linger "$USER"
```

To stream the **KDE desktop** (Gaming Mode needs neither step): log out and back into the Desktop
session once, then seed the input grant so the host doesn't wait on a dialog nobody answers:

```sh
bash /usr/share/lilynk/bazzite/kde-desktop-setup.sh
```

## 4. Open the firewall

Bazzite runs **firewalld**, and no client reaches the host until you open it. Open the host, and
the console for other devices:

```sh
sudo firewall-cmd --reload   # load the service definitions the image installed
sudo firewall-cmd --permanent --add-service=lilynk-native --add-service=lilynk-web
sudo firewall-cmd --reload
```

For [Moonlight](/docs/moonlight), also add `lilynk-gamestream` ([Ports & firewall](/docs/ports)).

a device.
