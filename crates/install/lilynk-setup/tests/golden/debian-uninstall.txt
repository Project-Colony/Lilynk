==> Uninstalling the host (https://project-colony.github.io/Lilynk/docs/uninstall)
  + systemctl --user disable --now lilynk-host lilynk-web lilynk-scripting 2>/dev/null || true
  + sudo apt purge -y lilynk-host lilynk-web lilynk-scripting
  + sudo rm -f /etc/apt/sources.list.d/lilynk.list /etc/apt/keyrings/lilynk.asc
  + sudo apt update

  Removed. Kept for a reinstall: ~/.config/lilynk, the lilynk, lilynk-door and lilynk-update groups,
  and your firewall rules.
  The one-command cleanups for each are on https://project-colony.github.io/Lilynk/docs/uninstall#linux-hosts
